주석의 `§N ID` 는 이 문서의 절 번호와 그 절 안의 ID 다(예: `§1 D4` = 엔진 절의 D4).

기준선(ARM 러너 4코어는 8코어 폰을 대변하지 못함).

## §2. UI 개편 — Mornye 벤치마크 (P0 ~ P5 2026-10-27 ~ 29, M1 ~ M7 2026-10-29)

Mornye(GPL-3.0, Flutter)의 코드는 옮기지 않았다. 구조(토큰 한 곳 · 감속 모드 게이트 · 연결 그룹 · 절제된 햅틱)와
화면의 모양 · 치수 · 색의 관계만 보고 Compose 로 새로 만들었다.

**경계 — 개편이 손대지 않은 것.** `data/**` · `domain/**` · `core/model/**` · `jniLibs/**`, ViewModel 공개 API,
`drawBoard`(화면과 PNG 내보내기가 같은 함수), 탭 좌표 매핑, 값의 색 `TagPalette`, `Color.kt` 램프(Zenyth Web
`tokens.golden.json` 909값과 묶임 — 역할 배정만 바꿀 수 있다), `settings.txt` 키. 판 주변에는 상시 도는 애니메이션 ·
블러 · 셰이더를 두지 않는다(분석 중 엔진이 코어 전부를 쓴다).

| ID | 결정 |
|---|---|
| D1 | 다이내믹 컬러는 크롬 톤만, 기본 꺼짐. 벽지 hue 는 `Ink`/`Neutral` 저채도 램프에만 |
| D2 | 블러 · 유리 없음. 불투명 틴트만 |
| D3 | 하단 탭 6개 유지, 가로/넓은 화면은 `NavigationRail` |
| D4 | 테마 시스템 · 라이트 · 다크 3상태 + AMOLED |
| D5 | Zenyth Web 과는 색 램프 · 토큰 값만 계속 일치, 시트 · 레일 · 햅틱은 안드로이드 고유 |
| D6 | 「미끄러지지 않는다 · 200 ms 이하」는 **판 영역 규칙**으로 좁히고, 크롬(시트 · 툴바 · 내비)은 스프링 허용. 감속 모드면 전부 현행 값 |
| E1 ~ E6 | (2차) 바탕을 살짝 차가운 흰색으로 · 카드 테두리 제거 · 설정은 목록 → 하위 화면 · 미니 분석 바 · 보드 시트 나무색 · 크기가 다른 툴바 버튼 그룹 |

**P0 — 스크린샷 골든.** Roborazzi + Robolectric(native graphics, SDK 35, `ko-rKR`, 420dp xhdpi). Gradle 플러그인 없이
`-Pscreenshots=record|verify|compare`. `screenshots.yml` 이 push 마다 verify, 수동 실행으로 record.
골든은 **CI 러너에서만 유효**(로컬 폰트 래스터가 다르다). 배운 것: 골든은 Gradle 입력이 아니라서 스크린샷 모드에서는
캐시를 꺼야 한다 — verify 녹색이면 로그에 `testDebugUnitTest FROM-CACHE` 가 없는지 본다. 토큰(`ZenythTokens`)은 값 불변
(`TokensTest`), 대비는 `ThemeContrastTest` 가 지킨다(새 스킴은 이 시험을 통과해야 들어온다).

## §3. 리팩토링 · 성능 · 위생 (Phase 0 ~ 7, 2026-10-29 ~ 31)

**규칙.** 화면 변화 0(골든 diff 0) · 기능 회귀 0 · 엔진은 바이너리 · 가중치 · 통신 · 엔진이 받는 값 어느 것도 바꾸지 않는다.

| 지표 | 시작 | 끝 |
|---|---|---|
| 릴리스 APK | 56.3 MB(v0.15.0) | **46.0 MB** |
| dex(압축 전) | 51.3 MB | **9.3 MB** |
| 엔진 줄당 ViewModel 할당 | 19,119 B | **4,323 B** |
| 분석 중 재구성/프레임 | 55.4 | **27.8** |
| 시계 틱 재구성/프레임 | 53.0 | **15.0** |
| 파서 / 집계기 할당 | 625 / 4,127 B/줄 | **120 / 628 B/줄** |

- **Phase 0 기준선.** `EngineStreams`(파서가 아는 모든 줄 모양) · `BoardFakes` · `BoardLiveScreenshotTest`(실제 화면 골든) ·
  `EngineIoBaselineTest`/`PerfBaseline` → `perf-baseline.yml`(`refactor/**` 브랜치 푸시와 수동 실행).
- **Phase 2 ~ 4.** 엔진 I/O 할당 축소, `BoardUiState` 슬라이스(`BoardSlices`), 재구성 범위 축소. 클립보드는
  `core/common/Clipboard.kt` 로 모아 넣는 내용 · 읽는 방식을 예전 API 와 같게.
- **Phase 7-1 R8.** `-dontoptimize -dontobfuscate`(안 쓰는 코드만 제거), 엔진 패키지(`data.engine` · `domain.engine`) 통째 보존.
  `build.yml` 이 푸시마다 릴리스를 빌드하고 APK 안의 엔진 파일 8개를 저장소 원본과 SHA-256 대조(`check_engine_files.py`).
- **Phase 7-5.** 화면 상태 사상을 `BoardUiMapper.kt` 로 이동(`BoardViewModel.kt` 1,025 → 759줄).
- **Phase 7-6.** 동결 사본 대조 시험을 `EngineIoGoldenTest`(파서 · 집계기 출력 해시 25개, `engine_io_golden.txt`)로 대체.

**하지 않은 것.** 판 정적 층 캐싱(아낄 몫 < 픽셀 변화 위험) · `analyze()` 를 Default 디스패처로(정지 → 최선수 두기 순서가
경합에 노출) · Baseline Profile(CI 에뮬레이터에서 7회 실패, 흔적 제거) · 시계 틱 주기 변경(엔진이 받는 남은 시간이 달라짐) ·
엔진 정지 경로의 `NonCancellable` 정리 · 가중치 40 MB 줄이기(오프라인 앱의 성격이 바뀜).

## §4. 보안 (2026-10-31)

계정 · 결제 · 서버 · 개인정보가 없고 소스가 공개다. 그래서 지키는 것은 **배포 경로**(진짜 APK)와 **입력 견고성**이다.

| ID | 무엇 | 처리 |
|---|---|---|
| S1 · S2 | Actions 를 움직이는 태그로 호출 · 서명과 빌드가 한 job | 커밋 SHA 고정, `release.yml` 을 세 job 으로 나눠 서명 키와 쓰기 토큰을 Gradle 빌드와 분리 |
| S3 | 태그 · `main` 보호 없음 | ruleset 셋(`main` 강제 push · 삭제 금지, `v*` 태그는 관리자만 생성 · 이동/삭제 금지) + `release` Environment(승인 필수). 서명 시크릿은 저장소 레벨 — `release.yml` 밖에서 `SIGNING_*` 를 쓰지 않는다 |
| S4 | Gradle 의존성 검증 | **보류** — S1 의 SHA 고정으로 대체 |
| S5 | 서명 키 단일 · 지문 미공개 | README 에 인증서 SHA-256 과 확인 방법 셋, 비상용 키 계보 절차(`publishing.md` §1-1, 실행은 필요할 때) |

## §5. 연구 탭 데이터 유도 · 형세 그래프 · 국면 카드 (R1 ~ R3, 2026-10-31)

RenjuNet 라이선스상 앱은 데이터를 받지도 싣지도 않는다 — 유도는 «사용자가 받은 파일을 고르게» 하는 데까지.

- **R1 국면 카드.** «둘 차례 · 수 · 마지막» 3칸 삭제, 기보 메뉴는 열기 · 저장 · 공유 · 이미지 4칸(형식 선택은 저장 · 공유 안).
  D8: 새 설치 기본 테마는 시스템을 따른다.
- **R2 데이터 유도.** 데이터 없이 오프닝 · 랭킹을 처음 열면 설치당 한 번 시트로 권하고, 큰 카드는 «나중에»로 얇은 배너까지
  접힌다. 수순 탭은 데이터를 쓰지 않으므로 아무것도 넣지 않는다(`GameDataPrompt`).
- **R3 형세 그래프.** 다시 그림(`EvalGraph`), 탭/끌어서 수 이동, 자리는 엔진 카드 아래.

## §6. 첫 실행 안내 — 온보딩 (O0 ~ O5, 2026-10-31)

Mornye 의 처음 설정 · 둘러보기를 기준으로 했지만 11화면은 많아 **최대 2화면**으로 줄였다(§0 개정).

- **처음 설정.** 1/2 환영(앱 마크 · 소개 · 기능 행 3, 왼쪽 위 언어 알약) → 2/2 알림 권한(마지막이라 «시작하기»).
  Android 12 이하는 알림 단계가 없어 환영 1화면. 화면 모드 · 기보 데이터 단계는 뺐다(이미 있는 자리에서 다룬다).
- **둘러보기(O3).** 자동으로 띄우지 않는다. 4쪽(보드 · 연구 · 정석 · 엔진), 설정 ▸ 정보 ▸ «둘러보기».
- 기존 사용자(업데이트)에게는 보이지 않는다. 엔진 자동 시작은 처음 설정이 끝날 때까지 미룬다.
  «새로워진 점» 창은 처음 설정 · 둘러보기가 모두 끝난 뒤에.
- 온보딩은 이미 있는 저장값(언어 · 테마 · 알림 권한)을 처음 한 번 묻는 창구일 뿐, 새 설정을 만들지 않는다.
